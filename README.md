# Green & Ethical Screener Starter

This is a beginner-friendly static website version of the screener.

## Files
- `index.html` - page structure
- `style.css` - styling
- `script.js` - sample data and slider filtering logic

## How to use
1. Unzip the folder.
2. Upload the files to a GitHub repository.
3. Connect the repository to Vercel.
4. Deploy.

## What this version does
- Lets you filter sample stocks and ETFs by green score and ethical score
- Shows ticker symbols
- Shows source links
- Calculates ETF scores from underlying holdings

## What it does not do yet
- It does not pull live stock or ETF data
- It does not use a database yet

That will come in the next stage.
